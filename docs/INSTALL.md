# Установка и первый запуск

Скачайте [Windows x64 Setup](https://github.com/Protozhe/witcher3-book-voice/releases/download/v0.1.3/WitcherBookVoice-0.1.3-Windows-x64-Setup.exe), запустите и завершите установку. Установка выполняется для текущего пользователя. Python устанавливать отдельно не нужно. Windows 10 версии 1809 или новее / Windows 11 x64; для Windows N нужен Media Feature Pack. Сборка не подписана: не отключайте защиту Windows; проверьте источник и контрольную сумму, если появилось предупреждение.

1. Установщик автоматически проверит русский голос. Если он отсутствует, мастер начнёт установку через Windows Update: подтвердите запрос администратора и дождитесь завершения. Если голос уже установлен, загрузки и запроса прав не будет. После отмены или сбоя можно повторить установку в мастере первого запуска. Windows может потребовать перезагрузку. При тихой установке проверка выполняется при первом обычном запуске приложения.
2. Мастер автоматически найдёт Steam и игру, подготовит мод и сохранит параметры обычного запуска. Steam один раз штатно закроется и откроется снова. Если игра открыта, сохранитесь и закройте её: программа не завершает игру принудительно. Отдельный ярлык и ручной ввод параметров не нужны. Остальные настройки Steam сохраняются; резервная копия записывается в папку steam-backups внутри данных приложения.
3. Запускайте Ведьмака как обычно из Steam: библиотека запускается автоматически в фоне. Дождитесь построения локального каталога. Для нестандартной установки или конфликтующих модов может понадобиться выбор папки игры или Script Merger.
4. Загрузите сохранение. Если библиотека пуста, выполните быстрое сохранение F5 и обновите список.
5. Подберите книгу. F7 запускает чтение; последующие карточки добавляются в очередь тем же нажатием.

Для оверлея рекомендуется оконный режим без рамки. Эксклюзивный полный экран может скрывать сторонние окна. Настройте сочетания, если они заняты игрой или другим оверлеем.

## Подготовка звука

Настройки → Подготовить озвучку заранее. Можно выбрать пробу на трёх книгах, свою библиотеку или каталог. Подготовку можно приостановить, а окна свернуть. Для другого темпа чтения нужен отдельный кэш.

## Данные и удаление

Установленная публичная версия хранит данные в LocalAppData/WitcherBookVoice/data. Обновляйте её новым установщиком в ту же папку: данные сохранятся. При удалении через Windows данные и игровые сохранения остаются. Их резервная копия перед крупным обновлением рекомендуется. Сначала выключите автозапуск в настройках, затем завершите приложение. Мод modW3LocalReader находится в папке Mods игры; удалять его следует при закрытой игре. Резервные копии подключения — .w3reader-backups в папке игры. Не удаляйте другие моды и сохранения.

## Linux

Linux-пакет пока отсутствует. Не считайте запуск Windows-программы через Wine подтверждённой совместимостью с отдельным Proton-префиксом игры.
